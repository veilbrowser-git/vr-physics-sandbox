# VR Physics Sandbox - builds

Download page for test builds of a standalone Meta Quest VR physics sandbox.

## Download

**[Download SandboxVR.apk](https://github.com/veilbrowser-git/vr-physics-sandbox/releases/download/v0.1.1/SandboxVR.apk)** (149 MB)

Current build: version 0.1.1 (Milestone A fixes). Development build.

What changed in 0.1.1: walking with the left thumbstick now works and is on by default, teleport and grabbing are fixed, and the controllers are replaced by realistic hands (skin tone and fit can be changed in the menu under Hands).
All builds are listed under [Releases](https://github.com/veilbrowser-git/vr-physics-sandbox/releases).

## Install on a Quest

1. Open this page in the headset browser and tap the download link above.
2. Open a file manager (for example CX File Explorer), go to Downloads and tap `SandboxVR.apk`.
3. If asked, allow that app to install unknown apps, then tap Install.
4. Launch **VR Physics Sandbox** from App Library > Unknown Sources.

## Controls

| Action | Control |
| --- | --- |
| Grab / release | Grip button, with your hand touching the object |
| Open / close menu | Left Menu button or Y |
| Press menu buttons, place items | Point the other hand at the menu or a surface, pull the trigger |
| Walk | Left thumbstick |
| Teleport | Right thumbstick forward, aim the arc, release |
| Snap turn | Right thumbstick left / right |
